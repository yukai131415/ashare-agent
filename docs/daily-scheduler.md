# 每日推荐调度

服务运行期间，按北京时间检查交易日和 14:30 截止点，每 30 秒检查一次。

- 14:30 前不启动当天抓取和预测。
- 14:30 后启动服务、电脑唤醒或错过检查时，发现当天没有有效结果会补执行。
- 失败、降级或没有推荐记录时，等待 120 秒后重试；发生异常不会终止检查线程。
- 成功日期保存到 `runtime/state/scheduler_state.json`，重启后不会重复执行当天任务。已有当天健康运行和推荐文件时也会识别已有结果。
- 多个调度器通过 `runtime/state/scheduler_state.lock` 操作系统文件锁互斥，进程退出后锁会释放。
- 周末及项目交易日历中配置的休市日跳过。

启动时的自动刷新也经过同一调度检查，页面顶部显示任务状态，控制台打印 `scheduler_*` 结构化事件。状态文件不保存模型密钥。

可在 `config/settings.json` 的 `scheduler` 下配置 `check_interval_seconds` 和 `retry_seconds`，默认分别为 30 和 120。电脑关机、休眠或服务退出时无法执行；恢复运行后会补执行当前交易日已到点的任务。

验证覆盖到点前、过点启动、失败重试、降级重试、重启去重、已有结果识别、进程互斥、跨日和 UTC 转北京时间。
