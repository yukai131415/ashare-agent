# 主 Agent 与受限自动恢复

主 Agent 在正式任务开始时调用系统配置的大模型，提交依赖图分发方案。现有 LangGraph 图继续执行真实 worker，行情与新闻并发，其余角色保持经过验证的依赖顺序。模型没有 shell、代码编辑、密钥修改、权限修改或变更选股规则的工具。

Worker 出错时，主 Agent 接收程序生成的错误类别、是否暂时性故障和次数，而不是完整堆栈、密钥或外部文本。程序先限定允许动作，再校验模型工具返回。可恢复错误包括超时、网络断开、429、部分5xx。401/403、格式变化、数据不足、无效证据不自动放行。正式推荐写入不自动重放。每个正式 worker 最多3次（还受原 max_retries 配置限制），重新执行真实 worker 成功才算恢复；失败仍会阻断下游。

主模型不可用时使用明确标记的安全规则兜底，不伪称模型已调用成功。主模型每次最长20秒，可能产生额外 Token 费用。用量和决策写入运行控制事件；不归入个人问答用量。

影子研究每个角色的生产模型传输暂时性故障允许主 Agent 判定后重试一次，仍受原实验时间/调用次数预算限制，不重放整个实验，不取消证据校验。既有格式修复和这次恢复共享一次修复机会。二次失败停止并显示需要处理。基本面数据为空、模型业务弃选不会冒充基础设施错误强行修复。

监控总览新增主 Agent / Worker 控制台，打开总览时每3秒读取最新100条事件；支持正式 worker、流程角色和影子阶段。事件持久化在 runtime/state/agent_control.db，控制台及 backend.jsonl 同时留痕。普通用户只看状态，不返回诊断正文、模型用量或内部策略。超过10分钟未更新的活动状态显示待确认，不能据此判定进程已经结束。

边界：这是进程内协调器，不是操作系统进程守护。Python进程崩溃、机器断电、代码解析器变更、服务商权限/余额问题必须由人工或外部服务管理器处理；不能保证修复各种错误。不自动启动重复服务，不终止不明进程，不交易、不修改策略，不以旧数据/假数据代替失败数据。生效需要重新启动现有后端服务。
