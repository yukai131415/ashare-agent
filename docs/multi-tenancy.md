# 登录、租户与用量统计

首次打开 http://127.0.0.1:8001/ 会进入管理员设置页。首次设置只允许本机完成，由系统所有者自行设置账号与至少10位密码；没有内置默认密码、没有公开注册入口。设置完成后自动登录，其他账号由管理员或经理创建。

| 角色 | 研究页面 | 账号管理 | Token统计 |
| --- | --- | --- | --- |
| 管理员 | 全部 | 创建任意租户下的管理员、经理和普通用户；创建租户；启停其他账号 | 全部租户，可按租户、用户、日期查询 |
| 经理 | 全部 | 仅本租户普通用户；不能创建经理、管理员或跨租户账号 | 不允许 |
| 普通用户 | 监控总览、每日简报（含问答） | 不允许 | 不允许 |

后端逐请求校验角色与租户，禁用账号立即撤销会话。页面隐藏不能代替权限校验。普通用户的综合读取接口不下发历史明细、月度表、完整候选排名、策略表现或板块数据。普通用户不能修改模型连接、触发采集或刷新回测。

## 隔离边界

- 行情、推荐、新闻及公开研报是本系统共同的研究数据，各租户共享；本次不改变原选股模型、定时任务或推荐历史。
- 登录账号、会话与归属统一存于 `runtime/security/accounts.db`；经理的账号列表只能看到本租户。
- 模型连接按租户保存，新增租户位于 `runtime/tenants/<tenant_id>/state/`，不继承默认租户密钥或全局密钥环境变量。默认租户保留现有 `runtime/state/` 配置，后台共享 Agent 继续使用原配置。
- 密码使用随机盐与 PBKDF2-SHA256（600000次）单向派生。Cookie 为 HttpOnly、SameSite=Lax，数据库仅保存会话令牌摘要；会话有效期8小时，POST校验CSRF令牌和Origin。
- 连续8次错误登录对该来源/账号组合限制15分钟。生产部署应使用HTTPS反向代理与额外入口限流，不能直接将开发HTTP服务公开到互联网。
- `runtime/` 已被Git忽略，备份账号库及租户配置时应按敏感资料管理。不要上传密钥或账号库。

## 内网穿透域名白名单

`config/settings.json` 的 `security.allowed_hosts` 可加入**完整且确切的域名**，例如：

```json
"security": {
  "allowed_hosts": ["ab63dda4.natappfree.cc"]
}
```

只填域名，不填 `http://`、路径或通配符，不要放开整个 `*.natappfree.cc`。本机 localhost、127.0.0.1、::1 仍可访问。修改后重启服务；免费隧道换域名时，删除旧域名并改成新域名。

隧道转发到 `127.0.0.1:8001`，应保留公网访问域名的 Host；浏览器请求的 Origin 必须与该 Host 匹配。系统不会信任任意 `X-Forwarded-Host` 来绕过校验，也不会取消登录、角色授权或CSRF令牌。首次管理员设置禁止从外部域名执行。无需将应用绑定到0.0.0.0，也无需开放路由器公网端口。

免费HTTP隧道只能验证连通性，不要在公网输入真实密码；正式分享必须使用可信的HTTPS入口。平台终止TLS时会处理网站请求，应使用可信供应商，不能把隧道令牌或API Key发到聊天里。

## Token口径

登录用户的投研提问、经理/管理员连接测试都通过服务端身份关联租户和用户，不能用客户端传入的用户ID覆盖。连接测试也可能产生真实用量，单独标识用途。

发送Token取服务商 `usage.prompt_tokens` 或 `usage.input_tokens`；响应Token取 `usage.completion_tokens` 或 `usage.output_tokens`。只统计实际返回的数字，未返回的显示“未报告”；汇总计数是**已报告部分**而非完整账单，不按字符数估算、不把本地回答算成模型消耗。urllib失败后的独立curl响应单独累计，重复落库不会重复计数。

页面提供已报告发送/响应总数、请求数、未报告响应数、用户汇总、每日汇总，以及每页10条的调用明细。失败和本地规则单独标识。统计数据库不保存提问或回答正文；原控制台结构化日志继续工作，并附带用户/租户ID。

功能启用前的调用没有可信用户身份，不能补造个人统计。后台共享Agent不归属任意登录用户，也不混入个人用量；本页不是供应商计费账单。

测试：`python -m unittest discover -s tests -p test_auth.py -v`。隔离页面验收脚本为 `tests/preview_auth.py`，只使用临时目录和测试会话，**不要作为正式服务启动入口**。
