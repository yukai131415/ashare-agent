# 菜单式投研工作台

顶部通过六个菜单切换，日期选择与自动任务状态共用。菜单支持键盘方向键、Home/End，并保存上次打开的位置。

| 菜单 | 内容 |
| --- | --- |
| 监控总览 | 原动态链路、样本池涨跌分布、上涨占比、成交活跃度、推荐因子贡献与前两名分差 |
| 候选排行 | 原模型完整归档排序，按名称/代码搜索，按评分/涨幅/成交额/换手率/量比排序，十条一页；点选查看贡献 |
| 策略表现 | 推荐日收盘至下一交易日收盘的独立价格研究、沪深300同窗口比较、成本假设、最大回撤、连亏、逐笔记录 |
| 板块热点 | 真实行业行情热力图、板块搜索与涨跌排序、最新个股行业归属、数据来源及时间 |
| 每日简报 | 所选日期的归档推荐、风险、财务同比、报告期、公告日和研报原文引用；原新闻、问答和模型管理入口 |
| 历史回测 | 原有月度统计、评分排序和历史回测，保留原来的最高涨幅减一点口径 |

## 数据边界

- 候选池情绪来自与推荐价格、分数和因子逐项匹配的分析归档，不使用当前行情重建旧推荐；找不到匹配归档时显示资料缺口。采集样本不代表全市场。
- 分数贡献严格使用现有三套公式及估值封顶规则。旧评分版本不能验证时不展示推算贡献，新闻不计分。
- 新增页面不写入推荐数据库、原回测记录或模型状态。
- 财务仅引用所选日期以前公告的数据；研报引用来自原工作流归档。
- 日线使用腾讯公开历史日线，不复权；请求和返回数据保存于 `runtime/research_dashboard/daily`。股票与沪深300必须同时有对应日期收盘价，目标日未收盘不计算。
- 收盘价研究默认买卖各扣 0.10% 的假设成本，允许用户调整。采用全仓轮换、碎股的理论价格计算，未验证收盘成交、滑点和整手限制；未计分红及公司行动。一字价日排除。
- 缺失记录不按零收益计入。曲线、回撤、连亏均为已匹配样本片段的研究统计，不能当作真实账户结果；同时展示覆盖率和逐笔状态。
- 板块优先采集东方财富行业列表，保留原响应。不可用时采用新浪官方行业分类并标注来源；不同来源分类不能混合相加。新浪接口未提供行情时间或金额统一单位的字段不会推造。
- 推荐股行业资料可使用新浪公司资料中的申万分类，标注其与板块榜单分类的区别；最新归属不回填为历史归属。

## 补充数据

点击策略表现或板块页的更新按钮会启动后台补充任务，不重新选股。任务状态、分来源失败原因与原始数据保存在 `runtime/research_dashboard`。日常推荐任务成功后异步补充研究数据，不阻塞推荐发布。

服务运行期间，15:10 后检查并补充缺少的收盘日线。采集于当日收盘确认前的日线，即使时钟已过收盘，也不会自动被认定为收盘价；必须刷新并核验采集时间。

接口：`GET /api/research-dashboard?date=YYYY-MM-DD` 为只读；`POST /api/research-dashboard/sync` 启动补充任务。成本参数 `buy_cost_pct`、`sell_cost_pct` 限制为 0～5%。
