# 全角色策略保密展示

管理员、经理、普通用户均只看到“保密策略”，没有管理员查看真实策略的网页开关。

- 前端HTML不附真实选股策略名称及标准化因子说明。
- 看板、候选排行、历史回测及研究接口通过服务端投影移除内部模型名称、版本、标准化因子、权重、阈值、评分贡献、比较差额和原始协作诊断。
- 页面只保留公开行情、股票结果、真实综合评分及真实回测；“公开行情概览”不表示列出的指标一定参与评分。
- 问答只向租户大模型传递脱敏后的公开快照，不传内部流程解释。直接请求公式、权重、源码、阈值或提示词的问题返回保密说明；回答中的已知内部模型名称与公式模式会被拦截。
- 计算模型、选股排序、锁定机制、推荐库、行情库、回测数据均不改变。真实策略仍保存在服务器代码与本地归档，不对浏览器提供。

## 保护边界

这是服务端数据最小化，不是给用户展示一套虚假的选股逻辑。不能保证完全防止根据大量公开输出反推算法，也无法阻止别人模仿前端外观；前端资源本身必须送达浏览器。综合评分、候选排名、公开行情和历史推荐仍可形成观察样本。

已经发布到公开GitHub仓库的代码、历史提交和他人副本不会因为网页保密而消失。如有保密要求，须另行处理仓库可见性与历史泄露；本次没有更改GitHub权限或推送代码。不得在公开仓库、前端资源和日志下载接口中放置秘钥或真实策略源码。

生产环境应同时限制账号共享、自动采集与查询速率，并确保只映射网站入口而非项目目录或数据库端口。旧页面、已经下载的JSON或已返回的大模型回答不能追溯撤回，部署后请刷新页面。
